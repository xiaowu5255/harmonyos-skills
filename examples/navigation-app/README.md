# 示例：Navigation 多页应用

展示 skill: **arkui-patterns** / **stage-model**

## 涉及知识点
- NavPathStack 路由管理
- UIAbility 生命周期（onCreate / onWindowStageCreate / onForeground / onBackground）
- Navigation + NavDestination 页面栈
- 页面间参数传递

## 文件说明
- `entry/src/main/ets/entryability/EntryAbility.ets` — UIAbility 入口
- `entry/src/main/ets/pages/MainPage.ets` — 主页（含 Navigation）
- `entry/src/main/ets/pages/DetailPage.ets` — 详情页
- `entry/src/main/ets/pages/SettingsPage.ets` — 设置页
