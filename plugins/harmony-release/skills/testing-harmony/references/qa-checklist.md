# 发布前 QA 检查清单(逐项打勾)

> 配合 testing-harmony 技能使用。各项的"怎么测"见技能正文对应章节;
> 阈值数字由团队按产品定,定了就写进本文件团队私有副本,不拍脑袋。

## 功能
- [ ] 核心业务逻辑单测通过,覆盖关键分支与边界值
- [ ] 关键路径 UI 冒烟通过(登录、主流程、支付/核心转化路径)
- [ ] 任意入口直达页面参数处理正确(卡片/推送/分享/深链拉起)
- [ ] 异常分支:无网/弱网/服务端错误码,均有兜底 UI 不白屏不崩溃

## 稳定性
- [ ] 随机压力遍历 ≥ 团队约定时长,零 crash / 零 ANR
- [ ] 核心场景长稳挂测,内存无持续上涨(前后快照对比)
- [ ] 前后台反复切换、横竖屏/折叠反复切换不崩不丢状态

## 兼容性
- [ ] compatibleSdkVersion 下限真机全流程跑通
- [ ] sm/md/lg 断点 + 折叠屏展开过程 + PC 窗口缩放无布局错乱
- [ ] /harmony-api-scan 无超版本裸调用
- [ ] 深色模式、字体缩放档位检查
- [ ] (发布级)云测兼容性专项通过

## 性能与功耗(阈值引用 performance-tuning 基线)
- [ ] 冷启动时长 ≤ 团队阈值(Profiler Launch 实测)
- [ ] 核心列表滑动无明显丢帧(Frame 模板验证)
- [ ] 退后台后无残留高频任务(后台任务类型合规)

## 安全合规(详见 security-permissions / release-and-compliance)
- [ ] 权限清单最小化,user_grant 均有真实 reason
- [ ] 用户同意隐私政策前抓包验证零数据上报
- [ ] 敏感数据加密存储(密钥走系统密钥库,无硬编码)
- [ ] release 包(混淆后)真机实测核心流程

## 测试件管理
- [ ] Beta 包 versionCode 已递增、签名正确
- [ ] 缺陷全部闭环或带已知问题清单评审通过
- [ ] 本轮新发现的典型问题已 /harmony-feedback 回流
