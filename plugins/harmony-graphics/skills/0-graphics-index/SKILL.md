## Overview

鸿蒙图形能力领域索引，覆盖 2D 绘制、3D 渲染、AR 增强现实、图形加速、空间感知。

## When to Use

- 涉及 Canvas 2D 绘制、路径/渐变
- 3D 渲染、ETS 场景
- AR 增强现实、空间感知
- 图形加速、GPU 相关优化

# 鸿蒙图形能力索引
